# Java Day 50 – Event Registration Management System

## Description
A Java application that manages student registrations for workshops, seminars, and conferences.

## Features
- Display available events.
- Register students for events.
- Track available seats.
- Prevent duplicate registrations.
- Search registrations using ID.
- Cancel registrations.
- Store registration records in a text file.

## Files
- `Main.java` – Main Java application.
- `registrations.txt` – Sample registration database.

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```

## Concepts Used
- Object-Oriented Programming
- Classes and Objects
- ArrayList
- HashMap
- File Handling
- Lambda Expressions
- Exception Handling

## Note
Event capacities are stored in the program. Registration records are saved in a local text file.
